# Task Manager Clean

Простая версия менеджера задач без Python — только HTML, CSS и JavaScript.  
Проект создан заново для чистого старта.

## 🚀 Функционал
- Добавление задач через поле ввода
- Отображение списка задач
- Минимальное оформление (CSS)
- Логика на чистом JavaScript

## 📂 Структура
task-manager-clean/
├── index.html   # основной файл
├── style.css    # оформление
└── script.js    # логика задач

## 🔧 Запуск
1. Откройте `index.html` в браузере локально  
2. Или используйте GitHub Pages:  
   https://allanazarovyuldosh-tech.github.io/task-manager-clean/
