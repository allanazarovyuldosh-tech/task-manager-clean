# Task Manager Clean

Простая версия менеджера задач на HTML, CSS и JavaScript.  
Проект создан заново для чистого старта.

## 🚀 Функционал
- Добавление задач
- Удаление задач
- Редактирование задач
- Отметка «Выполнено» (галочка)
- Сохранение в LocalStorage

## 📂 Структура
task-manager-clean/
├── index.html   # основной файл
├── style.css    # оформление
└── script.js    # логика задач

## 🔧 Запуск
1. Откройте `index.html` в браузере локально  
2. Или используйте GitHub Pages:  
   https://allanazarovyuldosh-tech.github.io/task-manager-clean/
